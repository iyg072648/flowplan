# 📝 2학기 프로젝트 제안서

## 1. 프로젝트명
**FlowPlan (플로우플랜) : 목표 달성을 위한 AI 기반 적응형(Adaptive) 스터디 플래너**

## 2. 프로젝트 배경 및 문제 정의
*   **문제점:** 대다수의 학생 및 수험생들은 방대한 분량의 학습(전공 서적, 자격증 시험 등)을 앞두고 초기 계획을 세우는 데 큰 어려움을 겪습니다. 또한, 불가피한 사정으로 하루 이틀 학습이 밀리게 되면, 기존의 고정된 계획표는 무용지물이 되고 결국 학습을 포기하거나 벼락치기를 하게 되는 악순환이 발생합니다.
*   **해결책:** 사용자가 학습할 분량과 기간만 입력하면 AI가 매일의 적정 학습량을 분배해 주고, 진도가 밀렸을 경우 남은 기간에 맞춰 **자동으로 스케줄을 재조정(Rescheduling)** 해주는 능동적인 플래너가 필요합니다.

## 3. 핵심 기능 (Core Features)
1.  **AI 스마트 목표 분할 (Smart Task Breakdown)**
    *   사용자가 전공 서적의 목차 사진을 찍어 올리거나 텍스트로 입력하면, OCR(광학 문자 인식) 및 LLM을 활용해 챕터별 난이도와 분량을 분석합니다.
    *   설정한 목표 기간에 맞춰 매일 해야 할 구체적인 Task(예: 3장 1절~2절 읽고 요약하기)로 자동 분할하여 캘린더에 등록합니다.
2.  **동적 스케줄링 및 피드백 (Adaptive Rescheduling)**
    *   가장 핵심적인 기능으로, 사용자가 특정 일자의 Task를 완료하지 못했을 경우 '재조정' 버튼을 누르면 AI가 남은 학습 기간과 기존 학습 페이스를 계산하여 **초과된 분량을 남은 일자에 합리적으로 재분배**합니다.
3.  **학습 몰입도 측정 및 시각화 (Focus Tracker & Analytics)**
    *   앱 내에 뽀모도로(Pomodoro) 타이머를 내장하여 실제 집중해서 공부한 시간(순공 시간)을 측정합니다.
    *   목표 달성률, 일간/주간 학습 시간 통계를 차트로 시각화하여 제공하고, AI가 학습 패턴을 분석해 "금요일 오후에 집중력이 떨어지니, 해당 시간엔 복습을 배치할까요?"와 같은 맞춤형 조언을 제공합니다.

## 4. 기술 스택 (Tech Stack)
*   **Frontend (모바일 앱 혹은 PWA):** React Native 또는 Flutter (안드로이드/iOS 동시 지원)
*   **Backend:** Node.js (Express) 또는 Spring Boot
*   **Database:** PostgreSQL (사용자 데이터, 스케줄 정보)
*   **AI & 3rd Party API:**
    *   OpenAI API (GPT-4o/3.5-turbo): 일정 분할 및 재조정 프롬프팅
    *   Google Cloud Vision API (또는 Tesseract): 교재 목차 이미지 OCR 인식
*   **협업 및 배포:** GitHub, Notion(문서화), AWS (EC2/RDS) 또는 Vercel/Render
