# FlowPlan 모바일 웹 화면 명세서

## 1. 공통 정책
### 1.1 서비스 개요
FlowPlan은 시험이나 학습 목표를 등록하면 학습 범위를 일별 일정으로 나누고, 진행 상황과 통계를 관리할 수 있는 모바일 웹 서비스입니다.

### 1.2 공통 레이아웃
| 영역 | 명세 |
| :--- | :--- |
| 상단 헤더 | FlowPlan 로고, 메뉴 버튼, 알림, 프로필 버튼 |
| 사이드 메뉴 | 대시보드, 캘린더, 학습 통계, 마이페이지, 진행 중인 목표 |
| 모바일 하단 메뉴 | 홈, 캘린더, 새 목표, 통계, 마이페이지 |
| 콘텐츠 영역 | 현재 선택한 메뉴의 주요 콘텐츠 표시 |
| 토스트 | 완료, 일정 생성, 재조정 등 사용자 작업 결과 안내 |
| 모달 | Task 상세, 타이머, 일정 재조정 등에 사용 |

### 1.3 모바일 하단 내비게이션
| 메뉴 | 이동 화면 |
| :--- | :--- |
| 홈 | 대시보드 |
| 캘린더 | 학습 캘린더 |
| + | 새 목표 등록 |
| 통계 | 학습 통계 |
| 마이 | 마이페이지 |

### 1.4 반응형 기준
| 화면 크기 | 동작 |
| :--- | :--- |
| 데스크톱 | 좌측 사이드바와 상단 헤더 표시 |
| 태블릿 | 일부 우측 보조 콘텐츠 숨김 |
| 모바일 | 사이드바 숨김, 햄버거 메뉴와 하단 내비게이션 표시 |
| 500px 이하 | 카드, 캘린더, 폼, 모달을 작은 화면에 맞게 재배치 |
| 360px 이하 | 히어로 영역과 하단 내비게이션을 초소형 화면에 맞게 축소 |

## 3. 인증 화면
### AUTH-01. 시작 및 소셜 로그인
**화면 목적**
신규 또는 기존 사용자가 서비스에 진입할 수 있도록 로그인 수단을 제공합니다.

**주요 구성**
| 영역 | 요소 | 명세 |
| :--- | :--- | :--- |
| 브랜딩 | FlowPlan 로고 | 서비스 로고 및 브랜드명 표시 |
| 소개 | 메인 카피 | “계획은 가볍게, 성장은 꾸준하게.” |
| 소개 | 보조 카피 | 서비스의 목표 및 학습 가치 설명 |
| 로그인 | Google 버튼 | Google 로그인 진입 |
| 로그인 | 카카오 버튼 | 카카오 로그인 진입 |
| 체험 | 체험 계정 버튼 | 인증 없이 대시보드 확인 |
| 안내 | 데모 안내 | 소셜 로그인이 데모임을 표시 |

**사용자 동작**
| 동작 | 결과 |
| :--- | :--- |
| Google로 계속하기 | 프로필 설정 화면으로 이동 |
| 카카오로 계속하기 | 프로필 설정 화면으로 이동 |
| 체험 계정으로 둘러보기 | 기본 사용자 정보로 대시보드 이동 |

**예외 및 상태**
* 현재 프로토타입에서는 실제 소셜 인증을 수행하지 않습니다.
* Google/Kakao 선택 시 신규 사용자 흐름으로 처리합니다.

### AUTH-02. 프로필 설정
**화면 목적**
신규 사용자의 닉네임과 목표 시험 정보를 설정합니다.

**입력 항목**
| 항목 | 유형 | 필수 | 명세 |
| :--- | :--- | :--- | :--- |
| 닉네임 | 텍스트 입력 | 선택 | 미입력 시 기본값 ‘지민’ 사용 |
| 목표 시험 | 선택 상자 | 필수 | 수능, 공무원 시험, 자격증, 어학 시험, 기타 |

**버튼**
| 버튼 | 활성 조건 | 동작 |
| :--- | :--- | :--- |
| 시작하기 | 항상 활성 | 프로필 저장 후 대시보드 이동 |

**완료 상태**
* 환영 토스트를 표시합니다.
* 입력한 닉네임이 대시보드와 프로필에 반영됩니다.

## 4. 메인 대시보드
### HOME-01. 메인 대시보드
**화면 목적**
오늘의 학습 계획, 달성률, 밀린 학습 및 목표 진행 상황을 한 화면에서 제공합니다.

**4.1 인사말 영역**
| 요소 | 명세 |
| :--- | :--- |
| 영문 레이블 | YOUR LEARNING SPACE |
| 제목 | {닉네임}님, 오늘도 잘 해낼 거예요 |
| 설명 | 목표를 향한 학습을 격려하는 문구 |
| 새 목표 버튼 | 목표 등록 화면으로 이동 |

**4.2 오늘의 집중 카드**
| 요소 | 명세 |
| :--- | :--- |
| 제목 | “오늘의 작은 성취가 내일의 나를 만들어요.” |
| 진행 문구 | 오늘 할 일 개수와 완료 개수 표시 |
| 달성률 | 완료 Task 수를 기준으로 백분율 계산 |
| 오늘의 계획 보기 | 오늘의 할 일 영역으로 스크롤 |

*달성률 계산식:* 오늘 완료한 Task 수 ÷ 오늘 전체 Task 수 × 100

**4.3 밀린 학습 경고**
미완료 Task 중 예정일이 오늘보다 이전인 항목이 있을 때만 표시합니다.
| 요소 | 명세 |
| :--- | :--- |
| 경고 문구 | 밀린 학습 개수 표시 |
| 설명 | 일정 재조정 유도 |
| 일정 재조정하기 | 일정 재조정 모달 표시 |

**4.4 오늘의 할 일**
| 요소 | 명세 |
| :--- | :--- |
| Task 체크박스 | 완료 또는 완료 취소 |
| Task 제목 | 학습 항목명 |
| 목표 정보 | 연결된 목표명 |
| 예상 시간 | 분 단위 표시 |
| 상세 버튼 | Task 상세 모달 표시 |
| 전체 일정 보기 | 캘린더로 이동 |

**Task 상태**
| 상태 | 표현 |
| :--- | :--- |
| 미완료 | 빈 체크박스, 기본 제목 |
| 완료 | 녹색 체크박스, 제목 취소선 |
| 변경 완료 | 달성률과 완료 개수 즉시 갱신 |

**4.5 이번 주 학습 흐름**
| 요소 | 명세 |
| :--- | :--- |
| 요일 | 일요일부터 토요일까지 표시 |
| 날짜 | 해당 주의 날짜 표시 |
| 오늘 | 녹색 원형 강조 |
| 일정 표시 | 과목별 색상 점으로 표시 |
| 날짜 선택 | 해당 날짜를 선택한 상태로 캘린더 이동 |

**4.6 진행 상황 영역**
데스크톱에서 우측 보조 영역으로 표시합니다.
| 요소 | 명세 |
| :--- | :--- |
| 오늘의 진행 상황 | 원형 달성률 차트 |
| 완료한 할 일 | 완료 개수와 전체 개수 |
| 누적 학습 시간 | 완료한 Task의 예상 시간 합계 |
| 진행 중인 목표 | 목표명, 마감일, 진행률 |
| FlowPlan Insight | 학습 리포트 이동 버튼 |

*모바일에서는 핵심 콘텐츠 집중을 위해 우측 보조 영역을 숨깁니다.*

## 5. 목표 등록
### GOAL-01. 새 목표 설정
**화면 목적**
사용자가 학습 목표 이름과 완료 예정일을 입력합니다.

**진행 단계**
1. 목표 설정 → 2. 학습 분량 입력 → 3. 일정 생성

**입력 항목**
| 항목 | 유형 | 필수 | 명세 |
| :--- | :--- | :--- | :--- |
| 목표 이름 | 텍스트 | 필수 | 예: 수능 수학Ⅰ 개념 완성하기 |
| 목표 완료일 | 날짜 | 필수 | 오늘 이전 날짜 선택 불가 |

**버튼**
| 버튼 | 활성 조건 | 동작 |
| :--- | :--- | :--- |
| 대시보드로 돌아가기 | 항상 활성 | 대시보드 이동 |
| 다음 단계 | 목표 이름과 완료일 입력 | 학습 분량 입력 화면 이동 |

### GOAL-02. 학습 분량 입력
**화면 목적**
일정으로 나눌 학습 범위를 입력합니다.

**입력 방식**
| 방식 | 설명 |
| :--- | :--- |
| 직접 입력하기 | 목차 또는 단원을 텍스트로 입력 |
| 목차 이미지 업로드 | 이미지 선택 후 추출 내용을 확인하는 흐름 |

*직접 입력:* 줄바꿈 기준으로 각각 하나의 학습 단위로 처리합니다. 입력한 학습 단위 개수를 하단에 표시합니다.
*이미지 업로드:*
| 요소 | 명세 |
| :--- | :--- |
| 이미지 선택 | 이미지 형식 파일 선택 |
| 선택 결과 | 선택한 파일명 표시 |
| 추출 결과 입력 | 사용자가 아래 입력창에서 직접 확인 및 수정 |

*(데모 제한: 실제 OCR 실행 안 함. 이미지 선택 후 텍스트 입력 필요)*

**버튼**
| 버튼 | 활성 조건 | 동작 |
| :--- | :--- | :--- |
| 이전 단계 | 항상 활성 | 목표 설정 단계로 이동 |
| 일정 생성하기 | 학습 내용 입력 | 일정 생성 로딩 화면 표시 |

### GOAL-03. 일정 생성 로딩
**화면 목적**
입력한 학습 분량을 일정으로 변환하는 처리 상태를 안내합니다.

**구성**
| 요소 | 명세 |
| :--- | :--- |
| 로딩 아이콘 | 반복 애니메이션 |
| 제목 | “학습 일정을 만들고 있어요” |
| 설명 | 학습 범위를 일일 계획으로 나누고 있음을 안내 |
| 진행 표시 | 로딩 바 애니메이션 |

**완료 처리**
* 각 줄을 하나의 Task로 생성합니다.
* 오늘부터 하루 단위로 순차 배치합니다.
* 새 목표를 목표 목록에 추가합니다.
* 캘린더 화면으로 이동합니다.
* 일정 생성 완료 토스트를 표시합니다.

| 안내 | 앞으로의 일정에 다시 배치된다는 설명 |

| 옵션 | 설명 |
| :--- | :--- |
| 남은 기간에 균등 분배 | 하루에 조금씩 나누어 배치 |
| 난이도순 분배 | 난이도를 고려하는 일정 배치 방식 |

**버튼**
| 버튼 | 동작 |
| :--- | :--- |
| 닫기 | 변경 없이 모달 닫기 |
| 일정 재조정하기 | 밀린 Task를 재배치하고 캘린더 이동 |
