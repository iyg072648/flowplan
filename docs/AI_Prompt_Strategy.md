# PlanFit AI 프롬프트 방향성 리서치

## 1. 프롬프트 목적
PlanFit 애플리케이션 내에서 OpenAI API(주로 GPT-4o 또는 gpt-3.5-turbo)를 활용하여 두 가지 핵심 기능을 수행합니다.
1. **목표 자동 분할**: 사용자가 입력한 방대한 분량의 텍스트(교재 목차 등)를 분석하여 매일 수행 가능한 분량으로 쪼개기.
2. **동적 재조정**: 지연된 학습량을 남은 기간에 맞게 합리적으로 재분배하기.

## 2. 핵심 프롬프트 구조 설계 (초안)

### A. 목표 자동 분할 (Smart Task Breakdown)
* **System Prompt:** "너는 수험생의 학습 스케줄을 짜주는 전문적인 스터디 플래너야. 주어진 목차와 기간을 분석하여 매일의 학습 분량을 JSON 형태로 반환해."
* **Input Data (User):**
  - 총 기간: 30일
  - 학습 가능 요일: 월, 수, 금, 토
  - 교재 목차 (또는 OCR 추출 텍스트): [목차 텍스트]
* **Output Format (Expected JSON):**
  ```json
  {
    "tasks": [
      {"date": "2026-10-01", "content": "1장 1절~2절", "estimated_time": 120},
      {"date": "2026-10-03", "content": "1장 3절~마무리", "estimated_time": 90}
    ]
  }
  ```

### B. 동적 스케줄 재조정 (Adaptive Rescheduling)
* **System Prompt:** "현재 사용자의 일정이 밀린 상태입니다. 남은 일정과 밀린 분량을 파악하여 기존 스케줄을 수정하세요. 특정 날짜에 분량이 과도하게 몰리지 않도록 균등하게 분배해야 합니다."
* **Input Data (User):**
  - 밀린 분량: 2장 1절~3절
  - 남은 학습 기간: 15일
  - 기존 남은 스케줄: [스케줄 리스트]
* **Strategy:** 토큰 비용을 최소화하기 위해 전체 스케줄을 다 보내지 않고, '남은 스케줄 리스트'와 '밀린 Task'만 전달하여 재결합된 스케줄만 응답으로 받도록 최적화합니다.

## 3. 프롬프트 개선 및 테스트 방향
* **Temperature 설정:** 창의적인 답변보다는 일관된 구조의 스케줄 반환이 중요하므로 Temperature 값을 0.2 이하로 설정합니다.
* **토큰 최적화:** 목차 텍스트가 매우 길 경우, 불필요한 공백이나 소개말을 전처리(Pre-processing)로 제거한 뒤 API에 전달합니다.
* **JSON 모드 활용:** OpenAI API의 `response_format: { type: "json_object" }` 옵션을 강제하여 파싱 에러를 방지합니다.
