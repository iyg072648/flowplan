# FlowPlan 사용자 흐름도 (User Flow) 및 화면 명세

## 1. 회원가입 및 로그인 (Authentication)
* **[시작 화면]** -> 소셜 로그인 버튼(Google/Kakao) 클릭 -> **[회원가입/로그인 처리]**
* 신규 유저 -> **[프로필 설정 화면]** (목표 시험, 닉네임 설정) -> **[메인 대시보드]**
* 기존 유저 -> **[메인 대시보드]**

## 2. 목표 등록 및 스케줄 분할 (Goal & Task Setup)
* **[메인 대시보드]** -> '+' 버튼 클릭 -> **[새 목표 등록 화면]**
* 목표 이름 및 기간 설정 -> **[교재 분량 입력 방식 선택]**
  * 방식 A: 직접 텍스트 입력 (예: 1단원~5단원)
  * 방식 B: 목차 이미지 업로드 (OCR 처리 중 화면) -> 추출된 텍스트 확인 및 수정
* 완료 버튼 클릭 -> **[AI 스케줄링 로딩 화면]** -> 일정 생성 완료 알림 -> **[캘린더 화면]**으로 이동

## 3. 데일리 학습 및 타이머 (Daily Study & Timer)
* **[메인 대시보드]** -> 오늘의 To-Do 리스트 확인
* 특정 Task 클릭 -> **[Task 상세 화면]** -> '학습 시작' 버튼 클릭 -> **[타이머 화면]**
* 타이머 화면 (25분 진행 / 5분 휴식 등) -> 학습 종료 시 '완료' 체크 -> Task 상태 업데이트
* 남은 Task 목록 갱신

## 4. 스케줄 동적 재조정 (Adaptive Rescheduling)
* **[캘린더 화면]** 또는 **[메인 대시보드]** -> 지연된(미완료) Task 경고 표시
* '일정 재조정하기' 버튼 클릭 -> **[재조정 옵션 선택 창]** (남은 기간에 균등 분배 / 난이도순 분배)
* 확인 클릭 -> AI 재조정 로직 실행 -> **[캘린더 화면]** 스케줄 재배치 확인

## 5. 학습 통계 및 마이페이지 (Analytics)
* 하단 네비게이션 바 '통계' 클릭 -> **[통계 대시보드 화면]**
* 주간/월간 누적 집중 시간(Bar Chart) 및 목표 달성률(Pie Chart) 확인
* AI 피드백 텍스트 확인 (예: "금요일 오전의 집중도가 가장 높습니다.")
